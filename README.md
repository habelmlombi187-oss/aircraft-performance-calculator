# Aircraft Performance Calculator

A beginner Python project that calculates basic aircraft performance
parameters using fundamental aerodynamic equations.

## Features

- Calculate lift.
- Calculate drag.
- Calculate aircraft weight.
- Calculate dynamic pressure.
- Calculate lift-to-drag ratio.
- Interactive menu.
- Input error handling.
- Calculation by zero error handling.

## Equations

### Lift

L = 0.5 × ρ(air_density) × V²(velocity) × S(wing_area) × CL(coefficient_of_lift)

### Drag

D = 0.5 × ρ(air_density) × V²(velocity) × S(wing_area) × CD(coefficient_of_drag)

### Dynamic Pressure

q = 0.5 × ρ × V²

### Weight

W = mg

### Lift-to-Drag Ratio

L/D = CL/CD
