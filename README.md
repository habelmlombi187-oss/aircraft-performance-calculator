# Aircraft Performance Calculator

A beginner Python project that calculates basic aircraft performance  parameters using fundamental aerodynamic equations.

I created this project as part of my hands-on python programming practice as an aerospace engineering student.

## Features
The calculator can calculate:
- Lift force.
- Drag force.
- Aircraft weight.
- Dynamic pressure.
- Lift-to-drag ratio.
- All performance parameters at once.
- Handles invalid numerical input.
- Has an interactive menu system.

## Aerodynamic Equations

## Meaning of Abbreviations
L= Lift force(N)
D= Drag force(N)
ρ= Air density(kg/m**3)
V= Aircraft velocity(m/s)
s= Wing area(m**2)
CL= Coefficient of lift
CD= Coefficient of drag
W= Weight(N)
m= Aircraft mass(kg)
g= Gravitational acceleration(9.81m/s**2)


### Lift

L = 0.5 × ρ × V² × S × CL

### Drag

D = 0.5 × ρ × V² × S × CD

### Dynamic Pressure

q = 0.5 × ρ × V²

### Weight

W = mg

### Lift-to-Drag Ratio

L/D = CL/CD
